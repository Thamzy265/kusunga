# Kusunga plan

Phase: MVP. Approved by the PM on 2026-11-03 (deck: `docs/slides/mvp-plan.html`).

## Decided (PM, 2026-11-03)

- D1 tech stack: Flutter desktop UI + small native code (option A).
- D2 bank-details vault: its own milestone, M2.
- D3 crash reports and usage stats: none in M1.
- DPIA: a short DPIA before the beta (added to M1.9).
- Plan approved; M1.1 starts.
- M1.2 (2026-11-03): Mac key in the login keychain until M1.9 signed builds.
- M1.3 (2026-11-04): taken-shortcut reporting accepted as a Mac limitation (Windows only).
- M1.3 (2026-11-04): direct notarised Mac download with the App Sandbox on (ADR 0003); default picker shortcut ⌘⇧V / Ctrl+Shift+V; pasted item stays on the clipboard; design approved.
- M1.4 (2026-11-04): snippets in the same encrypted file; pasting a snippet does not add it to history; pinning copies (the item stays in history); the picker always opens on History; bank and card details allowed with a note until the M2 vault; design approved.
- M1.2 (2026-11-03): default history 200 items (range 10–5,000); keychain failure → memory only with a warning; Apple Developer account only if unsigned builds cannot use the Keychain; scope change approved.
Research behind this plan: `docs/marketing/competitor-research.md`.

## Goal

One app that keeps your clipboard history and your saved snippets, and pastes them with a shortcut. Desktop (Mac and Windows) comes first, because only desktop allows full clipboard history. Mobile follows as a snippets keyboard with history synced from desktop.

## M1 — Desktop MVP (Mac + Windows)

Everything stays on the device. No account, no server.

- [x] **M1.1 Project setup** — small. Repo, chosen stack, check command, CI on Mac and Windows, `qa-artifacts/` git-ignored.
  - AC: the check command runs on both OSes in CI and passes on an empty app that opens a window and a tray/menu-bar icon.
- [x] **M1.2 Clipboard history capture** — large (new local data store, personal data).
  - AC: text and links copied in any app appear in history within 1 second.
  - AC: history keeps the newest N items; N is set in settings (default 200, range 10–5,000); the oldest item is removed when the limit is reached.
  - AC: duplicates move to the top instead of being saved twice.
  - AC: history is stored encrypted on disk, with the key in the OS keychain (Mac Keychain / Windows Credential Manager).
  - AC: items marked secret by password managers (Mac `org.nspasteboard.ConcealedType`/`TransientType`/`AutoGeneratedType`; Windows `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory`=0, `Clipboard Viewer Ignore`) are never saved (moved from M1.6, PM 2026-11-03).
  - AC: the user can delete one item (with Undo) and clear all history (moved from M1.8, PM 2026-11-03).
  - AC: if the keychain cannot be reached, history is kept in memory only with a warning and is never written unencrypted (PM 2026-11-03).
  - Design: `docs/design/clipboard-history.md`, ADR 0002, UI spec `docs/ui/clipboard-history.md`, deck `docs/slides/clipboard-history.html` (approved 2026-11-03).
  - Brief note: save data safely on every exit path (tray Quit, Cmd+Q, Dock Quit, Windows logoff/WM_ENDSESSION), not only Dart's onQuit (reviewer note, 2026-11-03).
- [x] **M1.3 History picker and paste** — large (OS permissions, UI).
  - Done: ADR 0003 — direct notarised Mac download, App Sandbox on, PostEvent only (PM 2026-11-04).
  - Design: `docs/design/history-picker.md`, UI spec `docs/ui/history-picker.md`, deck `docs/slides/history-picker.html` (approved 2026-11-04).
  - AC: a global shortcut (default Cmd+Shift+V / Ctrl+Shift+V, changeable) opens a picker over the current app.
  - AC: type to search; arrow keys and Enter paste the item into the app that was in focus; Esc closes.
  - AC: the picker works with keyboard only and with a screen reader (VoiceOver, Narrator).
  - AC: if the Mac Accessibility permission is missing, the app explains why it is needed and how to grant it.
  - AC: Kusunga posts the paste keystroke only after confirming the app that had focus is in front again (up to 500 ms); otherwise, and for Windows admin windows, it copies the item and says "press ⌘V / Ctrl+V".
  - AC: after pasting, the pasted item stays on the clipboard (PM 2026-11-04).
  - AC: a shortcut taken by another app is reported where the OS reports it (Windows `RegisterHotKey` fails); on Mac the OS lets two apps share a shortcut and does not tell Kusunga, so this is a known limitation; the user can always choose another (PM 2026-11-04).
- [ ] **M1.4 Saved snippets** — large (new data store, personal data).
  - AC: create, edit, delete and reorder snippets with a name, content and type (phone, email, link, address, other).
  - AC: snippets show in the picker in their own tab, and pinning a history item turns it into a snippet.
  - AC: snippets are never removed by the history limit.
  - Design: `docs/design/saved-snippets.md`, UI spec `docs/ui/saved-snippets.md`, deck `docs/slides/saved-snippets.html` (approved 2026-11-04).
- [ ] **M1.5 Typed shortcuts** — large (keyboard monitoring, trust boundary).
  - AC: each snippet can have a shortcut such as `;email`; typing it in any app replaces it with the snippet.
  - AC: shortcuts do not fire in password fields or in apps on the ignore list.
  - AC: a single switch turns typed shortcuts off.
- [ ] **M1.6 Sensitive-content protection** — large (personal data).
  - (Secret-marker skip moved to M1.2.)
  - AC: an app ignore list (preset with common password managers and banking apps) stops capture from those apps.
  - AC: "Pause history" for 15 min / 1 h / until resumed, from the tray/menu bar.
- [ ] **M1.7 Settings and expiry** — small.
  - AC: history limit, auto-delete after a set time (never / 1 day / 7 days / 30 days), shortcut, launch at login, ignore list.
  - AC: the most private choice is the default where there is one (e.g. launch at login off until the user turns it on).
- [ ] **M1.8 Your data: export and delete** — small.
  - AC: export snippets (and optionally history) as a JSON file; import the same file.
  - AC: "Delete all history" and "Delete everything" remove all stored data and the keychain key.
- [ ] **M1.9 Signed installers and first beta** — large (release).
  - AC: a notarised Mac build and a signed Windows installer install and launch without OS security warnings.
  - AC: Hardened Runtime enabled for the macOS build (notarisation needs it).
  - AC: the Mac history key moves from the login keychain to the data-protection keychain, with a key move (read old item, write new, delete old) so no user's history is moved aside; must be done before the first external beta (PM decision 2026-11-03).
  - AC: release notes and a rollback plan exist; the PM approves the release.
  - AC: a short DPIA is written in `docs/design/dpia.md` and the PM signs it off before the beta.
  - AC: the app's licence page includes the SQLite3 Multiple Ciphers MIT notice (reviewer note, 2026-11-03).
  - AC: the minimum macOS (12.0, forced by Xcode 27.2 in M1.3) is stated in ADR 0003 or the README and in the release notes (reviewer note C7, 2026-11-04).
  - Before start: decide whether to build sqlite3mc from source instead of the SHA-256-pinned prebuilt download (reviewer note, 2026-11-03).

## M2 — Secure vault (bank details, IDs)

Needs its own design note, privacy section and deck before it starts.

- [ ] Vault for sensitive snippets: locked by Touch ID / Windows Hello, masked in the UI, never in history.
- [ ] Pasting a vault item marks it concealed and clears the clipboard after 30 seconds (setting).
- [ ] No card numbers or bank details ever leave the device in M2.

## M3 — Encrypted sync between devices

Needs its own design note, privacy section and deck. Decisions D6 and D7 first.

- [ ] Pair devices with a code; end-to-end encrypted; no account.
- [ ] Sync snippets and history; vault items sync only if the user turns it on.

## M4 — Mobile (iOS + Android)

Needs its own design note and deck. Mobile cannot record clipboard history in the background (iOS and Android rules).

- [ ] Snippets keyboard (iOS keyboard that does not need Full Access; Android keyboard).
- [ ] Save to Kusunga from the share sheet.
- [ ] History synced from desktop (after M3).

## Later

- Linux desktop — small share of users — trigger: > 100 requests or > 5% of website visits from Linux — noted 2026-11-03 by lead
- Opt-in crash reports — not needed while the beta is small — trigger: > 200 active beta users — noted 2026-11-03 by lead
- Lock Kusunga with Touch ID / Windows Hello — protects history at an unlocked computer — trigger: > 10 beta users ask, or the M2 vault ships — noted 2026-11-03 by lead
- Rich text in history (keep formatting) — plain text covers the main use — trigger: > 20 requests — noted 2026-11-03 by lead
- Hide picker previews while the screen is shared or recorded — trigger: ≥ 5 beta users ask, or the M2 vault ships — noted 2026-11-04 by lead
- Mac App Store build — App Review risk for posting ⌘V (ADR 0003) — trigger: ≥ 50 requests for an App Store version, or > 20% of website visitors leave at the download step — noted 2026-11-04 by lead
- Typo-tolerant picker search — trigger: ≥ 10 beta users report "can't find" in feedback — noted 2026-11-04 by lead
- Sharing snippets with a team — not part of the personal use case — trigger: > 20 requests from teams — noted 2026-11-03 by lead
- Refresh only the changed rows of the history list — the list reloads all rows (up to 2,000 characters each) after every copy, which is fine for 200 items — trigger: the list takes longer than 100 ms to refresh with 5,000 items, or idle CPU above 1% while copying — noted 2026-11-03 by developer
- Windows tray "Open picker" pastes into the previous window — the tray click itself takes focus, so Kusunga can't know which window had it; copy-only is safe — trigger: ≥ 5 beta reports about it — noted 2026-11-04 by developer
- Unicode-aware picker search (ß/ss, composed vs decomposed accents) — substring search with simple case folding covers most text — trigger: ≥ 3 beta reports of not finding accented or ß text — noted 2026-11-04 by lead
- Picker shortcut pressed within 120 ms of clicking away is ignored, and a click within 1 s of the target app quitting needs one extra click — nothing is lost or pasted — trigger: ≥ 3 beta reports, or the next change to the picker's dismiss logic — noted 2026-11-04 by lead (reviewer C1, N2)
- Picker test tidy-ups: the fake scheduler honours the 0.12 s delay (N1), remove the unused targetAlive parameter (N3), a source guard that runPaste uses the real permissionMask, and the signing-id guard also checks the local id outside macos/ios/tool/.github — trigger: the next change to these files or M1.9 start, whichever is first — noted 2026-11-04 by lead (reviewer notes)
- Snippet placeholders ({date}, cursor position) — not needed for fixed text like a phone number — trigger: ≥ 10 beta requests — noted 2026-11-04 by lead
- Snippet folders or tags — a flat list is enough at a few dozen snippets — trigger: median beta user has > 50 snippets, or ≥ 10 requests — noted 2026-11-04 by lead
- Paste counts and "most used" snippet order — no use until the list is long — trigger: median beta user has > 30 snippets — noted 2026-11-04 by lead
