Clipboard history

Everything you copy is kept, encrypted on your computer, so you can find it and copy it again.

Use the arrow keys to move between slides · Print to save as PDF

Problem and users

You copy something new and the old thing is gone

Who

Anyone on Mac or Windows who copies and pastes a lot.

The job they are doing

Get back text or a link they copied a few minutes or days ago.

Today's pain

The system keeps one item (Mac) or 25 items that vanish on restart (Windows).

Success measure

A copied item shows in Kusunga within 1 second, every time, and the last 200 items survive a restart.

Plan item M1.2. Design: docs/design/clipboard-history.md · Screen spec: docs/ui/clipboard-history.md · ADR 0002.

Scope for this step

Capture, keep safely, and let you clean up

In M1.2

  • Text and links you copy in any app
  • Keep the newest 200 (you can choose 10 to 5,000)
  • Same text again moves to the top, no duplicates
  • Encrypted file; key in your keychain
  • New: never save passwords that password managers mark as secret (moved forward from M1.6)
  • New: delete one item, clear all history

Not in this step

  • Shortcut picker and paste: M1.3 · Snippets: M1.4
  • Ignore list and pause: M1.6 · Auto-delete after a time: M1.7 · Export: M1.8
  • Images and files, trigger: > 30% of beta users ask
  • Lock with Touch ID / Windows Hello, trigger: > 10 beta users ask, or the M2 vault ships
  • Keep formatting (rich text), trigger: > 20 requests

All slides apply.

Options

How to watch the clipboard

Option A: our own small Mac and Windows code

  • We check the "this is a password" markers before reading the text
  • About 350 lines of Swift and C++ to look after
  • Medium effort

Option B: a ready-made Flutter package

  • Less code for us
  • It can't see the password markers, so passwords would be saved
  • Low effort, but fails a must-have

Recommendation

Option A, because keeping passwords out of history is the core of our privacy promise. Storage: one encrypted database file, key in the Mac Keychain or Windows Credential Manager (ADR 0002).

Security

Kusunga sees everything you copy, so we lock it down

Trust boundaries

  • Text from any app or website
  • Other programs on your computer
  • Backups (Time Machine, OneDrive)

Abuse cases

  • Malware copies the history file
  • A password ends up in history
  • A huge copy crashes the app
  • A website copies text that hides its real content

Mitigations

  • Whole file encrypted; key in your keychain
  • Password markers checked first
  • Copies over 1 MB skipped
  • Shown as plain text only; hidden characters made visible

If the keychain can't be reached, history is never written unencrypted. Full abuse cases: docs/design/clipboard-history.md.

Plan and how you'll check it

How it gets built

1 Encrypted store + limit→ 2 Mac and Windows clipboard watchers→ 3 History list, delete, clear→ 4 Test, review, QA

How we will check it

  • Tests: limit never exceeded, no duplicates, password-marked copies never saved, file unreadable without the key, no copied text in logs
  • QA on the real Mac app: copy → visible within 1 s, restart keeps history, delete/undo, clear, keyboard and VoiceOver; screenshots of each state
  • CI on Mac and Windows
  • What only you can check: allowing paste access if macOS asks, and copying from your own password manager to confirm it is skipped
