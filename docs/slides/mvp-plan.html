Kusunga: your clipboard, kept

Everything you copy, plus the things you paste every day, one shortcut away on Mac and Windows first.

Use the arrow keys to move between slides · Print to save as PDF

Problem and users

People retype the same details and lose what they copied

Who

Anyone who copies and pastes a lot across Mac, Windows and phone: office workers, freelancers, students.

The job they are doing

Paste something they copied earlier, or paste their phone number, email, links or address without typing them again.

Today's pain

Built-in tools forget fast (Windows keeps 25 items and clears them on restart). Most people need two apps, one for history and one for snippets.

Success measure

Beta users paste from Kusunga at least 10 times a day, and 40% still use it after 4 weeks (from in-app counts on the device only).

Source: docs/marketing/competitor-research.md (21 apps compared, checked 29 Oct 2026).

Scope for this phase

M1: a desktop app that keeps everything on your computer

In M1 (Mac + Windows)

  • Clipboard history with a limit you set (default 200)
  • Shortcut picker with search, pastes into any app
  • Saved snippets, and typed shortcuts like ;email
  • Skips password-manager copies; ignore list; pause
  • Export and delete all your data
  • Signed installers for a first beta

After M1

  • M2 bank-details vault · M3 encrypted sync · M4 iOS and Android
  • Images and files in history, trigger: > 30% of beta users ask
  • Linux, trigger: > 100 requests
  • Opt-in crash reports, trigger: > 200 active beta users
  • Team sharing, trigger: > 20 team requests

All slides apply. M2, M3 and M4 each get their own design note and deck before they start.

Options

How to build it

Option A: Flutter + small native parts

  • One screen design for Mac, Windows and later iOS and Android
  • Clipboard, shortcuts and paste still need some Swift and C++ code
  • Medium effort; fastest path to mobile

Option B: Tauri (Rust + web)

  • Very small, light desktop app
  • Mobile support is newer; keyboards still need native code
  • Medium effort on desktop; more risk on mobile

Recommendation

Option A, because we can reuse most of the app when we build the phone versions in M4. A third option, fully native per platform, gives the best feel but means writing the app four times.

Security

The app sees everything you copy, so it must be trusted

Trust boundaries

  • Other apps on the computer that can read the clipboard or our files
  • Content copied from websites and documents
  • Keyboard monitoring for typed shortcuts

Abuse cases

  • Malware reads the history file
  • A password is saved in history
  • A shortcut fires in a password box
  • Someone uses your unlocked computer

Mitigations

  • Encrypted storage, key in the OS keychain
  • Skip concealed items and ignored apps
  • No shortcuts in password fields
  • Pause, auto-delete, delete everything

Mac: org.nspasteboard.ConcealedType convention. Windows: clipboard history exclusion formats. Full abuse cases go in the M1.2–M1.6 design notes.
